# User Input Template

Use this when the user wants to generate a participant recruitment poster but has not provided enough detail. Ask for the concise version first; use the detailed version only when the project is formal, medical-device-related, or needs ethics/safety precision.

## Concise Template

```text
请按下面信息生成被试招募海报：

1. 实验名称/标题：
2. 一句话卖点/招募重点：
3. 实验类型/方法：
4. 实验内容：
5. 实验时间和时长：
6. 实验地点或线上平台：
7. 被试要求：
8. 报酬/奖励/路补：
9. 报名方式/二维码/联系人：
10. 备注格式：
11. 伦理批准号/课题组：
12. 风格偏好/参考图：
```

## Minimal Required Fields

If the user does not want to fill a long template, require only these seven fields:

- 实验标题或类型
- 实验内容
- 时间和时长
- 地点或线上平台
- 被试要求
- 报酬
- 报名方式或二维码

## Follow-Up Policy

Ask at most 1-3 follow-up questions. Prioritize missing fields in this order:

1. 报名方式/二维码 because the poster must drive action.
2. 报酬 and time/duration because they determine conversion and layout emphasis.
3. 被试要求 and safety exclusions because they affect compliance.
4. 研究类型 because it determines background motifs.
5. 伦理批准号 and organizer because they can be footer placeholders if missing.

If the user says to proceed with incomplete data, use clear placeholders such as `时间待定`, `地点待补充`, `二维码区域`, and `伦理审批信息待补充`.
